# Job Portal Backend API

A backend REST API for a Job Portal application built using Django and Django REST Framework.

## 🚀 Features

- User Signup & Authentication
- JWT Authentication
- Employer & Candidate Roles
- User Profile API
- Create and Manage Jobs
- Job Search
- Apply for Jobs
- Resume Upload
- Cover Letter Support
- Application Management
- Employer Application Management
- Protected APIs using JWT

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- Simple JWT
- SQLite
- REST API
- Postman
